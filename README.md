# C#/SQL Techincal Challenge 

This C# application demonstrates a library that can build SQL queries programmatically with C#.

## Personal setup

1. Clone the repository:

```bash
git clone https://github.com/Ayorastar/TechnicalChallenge.git
```

2. In Visual Studio 2026, open the 'TechnicalChallenge.slnx' file.

## Project notes
This project assumes that the user does not input any invalid data (e.g. SELECT * FROM test WHERE id BETWEEN 'bob' AND 'alice'). Validity checking would have to be done elsewhere if this was used in a real production environment.
As a tool to create select statements however, it is fully featured.
